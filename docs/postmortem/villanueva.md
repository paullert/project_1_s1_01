## Biggest challenge
My biggest challenge was the delete account functionality. Originally, I was just deleting the user from the table, but I relalized that,
that wasn't deleting their saved coins or saved point data. However, I was able to handle it by tracing the data through the repositories,
ViewModels, and database operations.

## Most valuable thing I learned
Dealing with the challenge mentioned before helped me understand how the user table, saved coins, and save points were connected. It also heleped me understand
how Android Compose screens communicate with ViewModels and repositories. Compose screen is responisble for displaying state and responding to user actions, while
the ViewModel and repository handle the data and database operations.
